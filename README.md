# EGmicro Lab · V3 ngspice 实验版

入口：https://panmingzhu0925-png.github.io/egmicro-lab/v3/EG12523.html

EG12523 双管正激的独立浏览器 SPICE 版本。沿用已确认的用户原理图坐标、走线、位号与器件参数，电路图直接生成 SPICE 网表，由 Web Worker 中的 ngspice WebAssembly 实际求解。没有调用旧版 JavaScript MNA 求解器，也不会改动原仓库的开发版或用户版。

引擎为 **ngspice 45.2**，通过 **EEcircuit-engine 1.9.0** 的开源浏览器接口运行。它与本机 KiCad 的 ngspice 46 不同，不能称为最新版。固定资产、哈希和许可证见 `v3/vendor/`；无需远程计算服务。

默认 220Vac/50Hz、16:5:1、2mH、47µH/4000µF，2→17→2A 可编程负载，仿真 0.85s。初次显示的默认波形由同一网表实际预计算生成，并校验网表 SHA-256；编辑电气参数后必须重新运行。完整求解可能需要数分钟。默认保存间隔 1µs，最大求解步长 200ns；放大短脉冲时应缩短仿真时长并减小记录间隔。预计算概览保留分桶极值及末2ms原始记录，其余区段不具备完整开关周期的时间分辨率。

双击元器件或其符号文字编辑参数；原图可继续移动、布线、保存及导入。V3 使用独立草稿空间，不覆盖原版本的浏览器草稿。每栏信号符号可点击开关，电压与电流分别量程，时间范围在左侧设置。

## 模型边界

- 交流整流桥的四只二极管、母线电解、启动电阻/电容、OUT→VCC、自举及辅助供电、三绕组耦合变压器、MOS、输出整流/续流与输出滤波来自实际图中连接。
- EG12523 是自建 **SPICE 工程宏模型**，不是厂家硅片模型。VIN 15/9V迟滞按用户确认；启动电流30µA按规格最大，工作电流2.3mA按规格典型；OUT目标钳位17V，RI公式决定频率，最大占空比46%，SS为10µA/3.5V。
- 已建立CS锁存/80ns消隐与FB开路70ms锁存、VIN欠压复位网表；独立保护时序用例尚未完成验收。CC恒流机制、1V过流故障、100/70ns驱动延时、抖频尚未完整实现。驱动仅电压源/电阻等效，未实现0.5/0.8A及0.8/1.2A电流限幅，也未闭合驱动电源能量账；驱动UVLO5V、VCC静耗1mA是实验假设。
- TL431/光耦采用跨导、CTR及20µs/10µs单极点等效，不是厂商模型。二极管型号保留ES5J、MBR20200CT、1N4148、ES1J，但数值模型为通用D；MOS为SW/C等效，未校准实物反向恢复、寄生和驱动尖峰。
- 未提供的寄生默认采用明确工程假设：电解每只ESR20mΩ、原/次/辅绕组电阻50/5/100mΩ、k=0.999、Coss200pF，均可在元件弹窗修改。这些值不是实测值，也未写入用户原图覆盖其显式参数。
- B由线性耦合电感的公共励磁磁链计算，去除各绕组的漏磁项，区分绕组总电流与励磁等效电流；无PC47/PC95非线性材料曲线，不模拟饱和、磁滞或损耗。1GΩ仅为次级共模参考，不用于隔离或EMI预测。

本版用于对比SPICE求解和调试模型，尚不能据此认定芯片瞬态、尖峰或保护已与实物吻合。已验证范围及结果见 `docs/VALIDATION.md`。

## 本地运行

在本目录运行 `node serve.cjs`，打开 `http://127.0.0.1:8083/v3/EG12523.html`。浏览器Worker模块需HTTP环境，不支持直接用file://打开求解。

界面测试：`npm install --ignore-scripts`，然后 `npm test`。默认使用Windows Edge，可通过 `EDGE_EXECUTABLE` 指定其他Chromium路径。`npm run test:full`实际求解完整默认工况，可能耗时数分钟并生成验证与默认缓存文件。
