# V3 验证记录 · 2026-11-13

此记录区分开源引擎、工程宏模型和实物验证。尚无EG12523硅片模型或实测波形拟合，不能把以下软件检查称为芯片功能全部验收。

## 实际完成的检查

- 用户原图的元件坐标、位号、标签偏移、路线、线宽及显式参数，与确认JSON逐项相等；V3单独存储草稿。
- 原理图直接生成SPICE网表，R/C/L/二极管/桥/绕组/MOS/反馈与启动支路来自连接关系。改参数后网表改变，未知元件或引脚报错；不使用旧JS MNA作为回退。
- 真实Windows Edge中验证变压器双击参数弹窗、Lm改值进入网表、运行/停止高亮与禁用状态、Worker停止、实际ngspice波形及各栏探针。修复了SVG重绘后快速双击被画布捕获的问题。
- 浏览器实际运行 **ngspice 45.2 WASM / EEcircuit-engine 1.9.0** 完整默认0.85s、内部最大步长200ns、输出1µs，共850000点，约455.4s。原始记录归约见DEFAULT_WAVE_VALIDATION.json；整段达到终点，所有返回值有限。相同电路在本机ngspice46也达到0.85s，约240.3s。
- 17A窗口0.820～0.829s平均输出24.22934V，恢复2A后0.840～0.850s平均24.27385V；上电全程最大26.45555V。均为该工程模型的结果，不是硬件指标。初次短时20ms运行只验证接口，不能替代这里的完整启动验证。
- 旁路的`.meas`差分表达式在该接口下没有生成对应向量，已删除无效测量指令。数值直接从保存的两个节点向量相减归约。缓存签名更新前严格确认，除这三条不参与电路求解的测量指令外，全部网表行与实际求解相同；缓存保留原签名和迁移说明。物理网表见VALIDATED_DEFAULT.cir。

## 默认预计算结果

default-wave-cache.json来自上述真实WASM求解。原850000点按500个时间桶保留各向量最大/最小值的实际时刻，取并集，并完整保留最后2ms记录；共13932点。没有合成PWM周期，也没有把旧JS求解的波形换标签。

默认网页校验完整网表SHA-256。任何电气参数、负载时序、时长或步长不匹配即不载入；编辑、手动运行或停止可撤销待载入结果。只改图形位置时，电气网表不变，保留当前结果。缓存概览不能用于其他区段的完整开关周期测量，短脉冲还受1µs记录间隔限制。

发布前实际浏览器回归已确认：开页载入预计算结果时不请求WASM引擎；B探针可切换；只移动布局保持结果；改输入电压清空旧结果和测量值；延迟返回的默认缓存不能覆盖已修改的参数；随后实际20ms求解、变压器参数弹窗、运行/停止均正常。网表及缓存签名、原图一致性与引擎资产SHA检查通过。
